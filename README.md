# Mint releases

Installers for **Mint**, the desktop control panel for make-engine.

- Download the latest `Mint-Setup-<version>.exe` from [Releases](../../releases/latest).
- Mint needs a license key, which you get when you buy it on Whop.
- Installed copies update themselves from here; you only download the installer once.

Nothing else lives in this repository: no source code, and no issues. For help, use the
support channel you got with your purchase.
